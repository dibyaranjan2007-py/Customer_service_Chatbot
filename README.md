# Customer Service Chatbot 💬

A lightweight, rule-based conversational assistant built in Python. This project simulates automated customer interactions, processing user queries and returning relevant predefined responses in real time.

---

## 🚀 Key Features

* **Real-Time Interaction:** Immediate text-based responses to user inputs.
* **Pattern Matching Engine:** Employs rule-based logic and pattern recognition to detect query intents.
* **Graceful Exit Handling:** Allows users to terminate conversations cleanly with standard exit commands (`bye`, `exit`, `quit`).
* **Clean & Modular Structure:** Easy to configure, extend, and integrate new conversation pairs.

---

## 🛠️ Built With

* **Language:** Python 3.x
* **Core Libraries:** Standard Python (`re`, `sys`) / NLTK utilities
